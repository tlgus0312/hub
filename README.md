# 🌿 식물 이미지 인식 머신러닝 프로젝트

## 📘 프로젝트 개요
이 프로젝트는 **직접 촬영한 식물 잎 이미지 데이터**를 활용하여  
조명 변화 환경에서도 견고한 분류 성능을 보이는 머신러닝 모델을 개발한 개인 프로젝트입니다.  

데이터 수집부터 전처리, 모델 학습, 차원 축소(PCA), 모델 선택(SVM vs Logistic Regression)까지  
머신러닝 파이프라인의 전 과정을 직접 수행하였습니다.

---

## 📆 개발 기간
2025년 3월 ~ 2025년 4월  

## 🧠 목표
- 실내 인공조명 및 자연광(창가 햇빛)에서 촬영된 식물 잎 데이터를 통해  
  **조명 조건 변화에도 강인한 분류 모델**을 구축하는 것
- 과적합 위험을 최소화하면서 높은 인식 정확도를 달성하는 것

---

## 📁 데이터 구성
- 직접 촬영한 식물 잎 사진으로 데이터셋 구축  
- 각 식물별 대표 잎 1장을 선정한 뒤, 다양한 조명 조건(실내 조명 / 자연광)에서 촬영  
- 조명, 배경, 각도, 거리 등 다양한 환경 요인을 반영하여 모델의 일반화 성능 확보  

## ⚙️ 전처리 및 특징 추출
- OpenCV를 활용한 이미지 리사이즈, 색상 보정, 노이즈 제거 수행  
- **PCA(Principal Component Analysis)** 를 사용하여 차원 축소 → 특징 공간 단순화 및 학습 효율 개선  
- 데이터 정규화(normalization) 적용  

---

## 🤖 모델 설계 및 비교
두 가지 머신러닝 모델을 비교하여 최적 모델을 선정하였습니다.

| 모델 | 훈련 정확도 | 테스트 정확도 | 훈련-테스트 차이 | 과적합 위험 |
|:------|:-------------:|:--------------:|:----------------:|:-------------:|
| SVM (Support Vector Machine) | 97.0% | 85.4% | 11.6% | 중간 |
| Logistic Regression | 97.0% | 85.4% | 11.6% | **낮음** |

> SVM 모델은 학습률이 100%로 나타나 과적합 현상이 발생하였으며,  
> 이를 완화하기 위해 **감마(gamma) 값을 0.001로 조정**하고, **PCA 기반 차원 축소**를 적용하였습니다.  
> 최종적으로 두 모델의 테스트 정확도가 동일했으나,  
> **Logistic Regression 모델이 과적합 위험이 더 낮고 일반화 성능이 안정적**이어서  
> 최종 분류 모델로 선택하였습니다.

---

## 📈 최종 성능
- **훈련 정확도:** 97.0%  
- **테스트 정확도:** 85.4%  
- **차이:** 11.6%  
- **모델:** Logistic Regression
